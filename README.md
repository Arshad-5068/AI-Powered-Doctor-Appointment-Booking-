#  AI Doctor Appointment Booking & Virtual Receptionist

An AI-powered system that automates doctor appointment booking using **WhatsApp, web forms, and workflow automation**, eliminating queues and improving healthcare efficiency.

---

##  Overview

Healthcare systems still rely on manual booking processes and long queues, leading to delays and inefficiencies.

This project introduces an **AI-powered virtual receptionist** that enables patients to:
- Book appointments via WhatsApp or form  
- Get instant confirmations  
- Avoid waiting lines  

---

## Problem

- Long queues in hospitals and clinics  
- Manual registration processes  
- Staff shortage at reception  
- Poor patient experience  

---

## Solution

An **AI-powered virtual receptionist** that:
- Automates appointment booking  
- Uses natural language (WhatsApp)  
- Integrates with scheduling systems  
- Sends confirmations via Email & WhatsApp
